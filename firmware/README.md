# ESP32 firmware

This directory will contain the program that runs on the microcontroller.

In Stage 1, we will create the `water_tank_monitor/water_tank_monitor.ino` sketch. Arduino requires the sketch directory and its main file to have the same name.

The first program will only measure distances and display them over the serial port. Calculations, Wi-Fi, and cloud uploads will be added in their respective stages, with an explanation of each change.
