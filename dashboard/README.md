# Web dashboard

The HTML, CSS, and JavaScript interface will be built here in Stage 5.

It will show the current water level, estimated liters, fill percentage, historical trends, the latest measurement's date and time, and a visual low-level alert. It will also distinguish recent readings from stale data.

Before implementation, we will explain how to query the selected storage service. Keys that allow measurements to be written must not be included in the JavaScript delivered to the browser.

**Status:** no code or installed dependencies yet.
